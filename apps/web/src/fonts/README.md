# Fonts

Self-hosted so builds never fetch from Google Fonts. Latin subsets, taken from
the Fontsource npm packages and loaded in `src/app/layout.tsx` with
`next/font/local`.

| File | Family | Licence |
| --- | --- | --- |
| `bricolage-grotesque-latin-wght.woff2` | Bricolage Grotesque, variable weight 200 to 800 | SIL OFL 1.1, `OFL-bricolage-grotesque.txt` |
| `ibm-plex-sans-latin-*.woff2` | IBM Plex Sans 400, 500, 600 | SIL OFL 1.1, `OFL-ibm-plex.txt` |
| `ibm-plex-mono-latin-*.woff2` | IBM Plex Mono 400, 500 | SIL OFL 1.1, `OFL-ibm-plex.txt` |
